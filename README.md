# produits_structures
Le but est de développer une application streamlit avec différents moteurs/modèles de pricing d'instruments financiers (principalement optionnels).

L'application se sert comme connection au marché d'une base de données de prix d'options sur Apple, et des prix du sous-jacent. Les modèles sont calibrés et font ensuite des simulations à partir de ces données.

Cette application a été créée dans un cadre universitaire et n'est pas vouée à être déployée dans le milieu pro.
